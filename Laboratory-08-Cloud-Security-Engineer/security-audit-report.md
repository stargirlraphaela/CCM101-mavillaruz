# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their tasks. It is important in cloud computing because it reduces the risk of unauthorized access, accidental changes, and data theft if an account is compromised.

## 2. Attack Surface

The attack surface refers to all the possible entry points an attacker could use to access a virtual machine or server. Examples include open network ports, running services, weak passwords, and outdated software. Reducing unnecessary entry points helps improve server security.

## 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a specific rule allows it. This is safer than trying to block individual attackers because unknown and unauthorized connections are also blocked automatically. Only the services that are actually needed should be allowed.
