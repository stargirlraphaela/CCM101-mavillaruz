# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed MinIO as an S3-compatible object
storage server using Docker. I created a storage bucket and uploaded a
sample file using the MinIO web console.

## Objectives

- Understand Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through a web browser.
- Create an object storage bucket.
- Upload an object to the bucket.
- Document the deployment using Markdown.

## Tools Used

- KillerCoda
- Ubuntu Linux
- Docker
- MinIO
- GitHub
- Web Browser
- Markdown

## Skills Learned

- Cloud storage concepts
- Docker deployment
- Linux command line
- Port forwarding
- Object storage management
- Technical documentation
