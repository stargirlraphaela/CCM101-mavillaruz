# Automation Research

## Bash Script

A Bash script is a file that contains Linux commands that can run together automatically. The `#!/bin/bash` line, called the shebang, tells Linux to use the Bash interpreter to execute the script.

## Variables

Variables store information, such as folder paths, file names, or dates, so they can be reused in a script. For example, `$BACKUP_DIR` stores the backup folder path, making the script easier to read and update without changing the path in multiple places.

## Cron Job

A cron job is a scheduled task in Linux that automatically runs a command or script at a specified time. It is essential in cloud operations because it helps automate repetitive tasks, such as backups and system maintenance, without requiring someone to run them manually.
