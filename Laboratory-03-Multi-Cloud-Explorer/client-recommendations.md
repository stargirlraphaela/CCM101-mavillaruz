# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended because the startup has a limited budget but expects rapid growth. AWS provides scalable services that allow the company to start with a small infrastructure and increase resources as the application gains users. Services such as Amazon EC2, Amazon S3, and Amazon RDS can support the application's computing, storage, and database requirements. AWS also provides many services that can be added later as the startup grows.

**Recommended Services:**

* Amazon EC2
* Amazon S3
* Amazon RDS
* AWS Lambda

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration easier and reducing compatibility issues. Microsoft Entra ID can also support identity and access management for users. Azure Virtual Machines and Azure SQL Database can be used to migrate existing applications and databases.

**Recommended Services:**

* Azure Virtual Machines
* Microsoft Entra ID
* Azure SQL Database
* Azure Blob Storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

Google Cloud is recommended because the company focuses on Artificial Intelligence and Machine Learning. Google Cloud provides AI and machine learning technologies, powerful compute resources, and data analytics services. It also provides specialized infrastructure suitable for demanding workloads. The company could use Vertex AI, Compute Engine, and Google Kubernetes Engine to build and operate AI applications.

**Recommended Services:**

* Vertex AI
* Compute Engine
* Google Kubernetes Engine
* Cloud Storage

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended for the global e-commerce company because it provides a large global infrastructure and many services designed for scalable applications. The company can distribute workloads across multiple regions and availability zones to improve availability. Auto Scaling can automatically adjust computing resources based on demand. Services such as Amazon EC2, Elastic Load Balancing, Amazon RDS, and Amazon CloudFront can support a global e-commerce platform.

**Recommended Services:**

* Amazon EC2
* Elastic Load Balancing
* Amazon RDS
* Amazon CloudFront
* Auto Scaling
