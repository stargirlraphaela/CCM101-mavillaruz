# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform for building, deploying, and managing applications and infrastructure. Azure was launched in 2010 and provides services for computing, storage, databases, networking, security, AI, and enterprise applications.

## Global Infrastructure

Azure operates a global network of Microsoft-managed datacenters and cloud regions. Its global infrastructure allows organizations to deploy applications in different geographic locations to improve performance, availability, and compliance.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Administrators can manage virtual machines, databases, storage, networking, security, and other services from the portal.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual servers for running Windows and Linux applications.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of unstructured data such as documents, images, videos, and backups.

### 3. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and cloud resources.

### 4. Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft SQL Server technologies.

## Three Advantages

1. **Microsoft Integration** – Azure works well with Windows Server, Microsoft 365, Active Directory, and other Microsoft technologies.
2. **Enterprise Support** – Azure provides services designed for large organizations and enterprise workloads.
3. **Hybrid Cloud Capabilities** – Azure supports connecting on-premises infrastructure with cloud resources.

## Typical Enterprise Use Cases

Azure is commonly used for:

* Windows Server workloads
* Microsoft 365 integration
* Enterprise applications
* Database systems
* Hybrid cloud environments
* Artificial Intelligence
* Business applications
