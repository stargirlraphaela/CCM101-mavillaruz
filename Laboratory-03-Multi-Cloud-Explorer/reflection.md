# Mission 3 Reflection

Completing Mission 3 helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. Among the three cloud platforms, Google Cloud impressed me the most because of its strong focus on Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. I also learned that AWS has a very broad selection of cloud services, while Azure is especially useful for organizations that already use Microsoft technologies.

AWS, Azure, and Google Cloud have many similarities. All three provide virtual machines, object storage, databases, networking, identity management, security services, and tools for application development. They also use a global infrastructure consisting of different regions and locations that allow organizations to deploy applications closer to their customers. Although their services have different names and features, they generally solve similar business and technical problems.

Business requirements are very important when selecting a cloud platform. A company should not choose a provider simply because it is popular. Instead, it should consider its budget, existing technology, performance requirements, security needs, location, scalability, and future plans. For example, Azure is a strong choice for a university that already uses Microsoft technologies, while Google Cloud can be a good choice for an AI research company.

Acting as a Cloud Solutions Consultant taught me that cloud decisions should be based on the client's actual requirements. I learned how to compare services between providers and recommend appropriate solutions for different scenarios.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I added organized Markdown documentation, comparison tables, recommendations, research findings, screenshots, and a reflection. This makes my portfolio more professional and demonstrates my growing knowledge of cloud computing and technical documentation.
