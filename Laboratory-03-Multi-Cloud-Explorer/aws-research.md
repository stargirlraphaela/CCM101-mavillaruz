# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It provides services for computing, storage, databases, networking, security, artificial intelligence, and many other IT requirements. AWS launched its cloud services in 2006 and has become one of the largest cloud platforms in the world.

## Global Infrastructure

AWS uses a global infrastructure made up of Regions, Availability Zones, Local Zones, and other edge infrastructure. AWS currently has 39 geographic Regions and 124 Availability Zones. Each Region contains multiple isolated Availability Zones that help organizations build highly available applications.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources. Users can access services such as EC2, S3, RDS, IAM, and many other AWS services through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides scalable object storage for files, backups, media, and other data.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) provides managed relational databases.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls user access and permissions to AWS resources.

## Three Advantages

1. **Large Service Selection** – AWS provides a very wide range of cloud services.
2. **Global Infrastructure** – AWS has a large worldwide infrastructure for deploying applications closer to users.
3. **Scalability** – Resources can be increased or decreased according to business requirements.

## Typical Enterprise Use Cases

AWS is commonly used for:

* Web and mobile applications
* E-commerce systems
* Data backup and storage
* Enterprise databases
* Artificial Intelligence and Machine Learning
* Disaster recovery
* Global applications
