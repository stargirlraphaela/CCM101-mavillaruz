# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), now commonly referred to as Google Cloud, is Google's cloud computing platform. It provides computing, storage, databases, networking, analytics, artificial intelligence, machine learning, and container services.

Google Cloud's cloud history includes the launch of App Engine in 2008, which became an important early Google Cloud service.

## Global Infrastructure

Google Cloud uses a worldwide infrastructure organized into regions and zones. As of August 31, 2026, Google Cloud lists 43 regions and 130 zones across its global infrastructure.

## Cloud Management Console

The Google Cloud Console is a web-based management interface used to create, configure, monitor, and manage Google Cloud resources.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can run applications and operating systems.

### 2. Cloud Storage

Cloud Storage provides scalable object storage for files, backups, media, and other data.

### 3. Cloud IAM

Cloud Identity and Access Management controls access to Google Cloud resources.

### 4. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy and manage containerized applications.

## Three Advantages

1. **Artificial Intelligence and Machine Learning** – Google has strong technologies for AI, machine learning, and data analytics.
2. **Kubernetes** – Google created Kubernetes and provides GKE for managed Kubernetes deployments.
3. **Global Network** – Google operates a large global network designed for high performance and low latency.

## Typical Enterprise Use Cases

Google Cloud is commonly used for:

* Artificial Intelligence and Machine Learning
* Big Data analytics
* Kubernetes applications
* Web applications
* Data warehousing
* Mobile applications
* Global services
