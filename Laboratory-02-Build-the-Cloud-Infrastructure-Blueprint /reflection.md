# Reflection

This laboratory activity helped me understand how the different components of cloud infrastructure work together to provide reliable and scalable services. Among the different components, I think compute resources are the most important because they provide the processing power needed to run applications, services, and operating systems. Without sufficient computing resources, other infrastructure components would not be able to effectively support applications and users.

Linux plays an important role in cloud computing because it provides a stable and flexible operating system for running servers and applications. During this activity, I used the KillerCoda Linux environment to investigate system information, including the CPU, memory, storage, network information, and operating system. Learning basic Linux commands gave me a better understanding of how cloud servers are managed.

Technical documentation is important before deploying infrastructure because it provides a clear record of the system design, resources, configurations, and decisions. Proper documentation helps engineers understand how the infrastructure should work and makes troubleshooting, maintenance, and future improvements easier. It also helps prevent mistakes when deploying or modifying cloud resources.

During this laboratory activity, I learned how to investigate a Linux cloud server using terminal commands and identify its compute, storage, networking, and operating system components. I also learned how to compare equivalent services from AWS, Microsoft Azure, and Google Cloud Platform. In addition, I improved my skills in Markdown, Git, GitHub, and creating a basic cloud infrastructure diagram.

My GitHub portfolio improved because I added a complete and organized laboratory project with multiple Markdown documents, investigation results, cloud provider comparisons, a reflection, and an infrastructure diagram. This made my portfolio more structured and demonstrated practical knowledge of cloud infrastructure. Overall, the activity improved both my technical skills and my ability to document and present cloud-related work professionally.
