# Cloud Provider Comparison

| Infrastructure Component                 | AWS        | Microsoft Azure                 | Google Cloud Platform       |
| :--------------------------------------- | :--------- | :------------------------------ | :-------------------------- |
| **Compute**                              | Amazon EC2 | Azure Virtual Machines          | Compute Engine              |
| **Storage**                              | Amazon S3  | Azure Blob Storage              | Cloud Storage               |
| **Networking**                           | Amazon VPC | Azure Virtual Network           | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS IAM    | Microsoft Entra ID / Azure RBAC | Cloud IAM                   |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

**AWS** is generally considered to offer the broadest range of cloud services. Its official product catalog covers many categories, including compute, storage, networking, databases, analytics, AI, security, developer tools, and more.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend **Microsoft Azure** because it has strong integration with Microsoft technologies and supports Windows Server, Microsoft products, and hybrid environments. Azure also provides services such as Virtual Machines, Microsoft Entra ID, and Azure services that can work with existing Microsoft infrastructure.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

**Google Cloud Platform (GCP)** is widely recognized for its strengths in artificial intelligence, machine learning, data analytics, and Kubernetes. Google Cloud provides AI/ML services and Google Kubernetes Engine (GKE), a managed Kubernetes service for running containerized applications.

### 4. What similarities did you observe among the three cloud providers?

The three providers offer similar core infrastructure services, including virtual machines, cloud storage, virtual networking, and identity and access management. They also provide scalable, managed services that allow organizations to deploy applications without owning and maintaining all of the underlying physical infrastructure.
